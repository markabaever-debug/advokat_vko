# advokat_vko — сайт адвоката Маркабаева Е.Б.

Next.js (App Router), публикуется на Vercel: https://advokatvko.vercel.app

## Публикация сайта — правила
- **Автопубликация.** Vercel разворачивает продакшн при каждом push в ветку `main`. Поэтому **любые правки делать только в отдельных ветках**, никогда не коммитить и не пушить прямо в `main`.
- **Проверка через preview.** Для показа изменений отправить ветку на GitHub (`git push -u origin <ветка>`) и дать адвокату **ссылку предпросмотра Vercel (preview deployment)** — Vercel создаёт отдельный временный URL для каждой ветки, прод при этом не меняется.
- **Слияние — по команде, без pull request.** Порядок всегда такой: правки в отдельной ветке → предпросмотр Vercel → слияние в `main` и push. Слияние в `main` делается **напрямую** (`git merge` + `git push`), **pull request не используется**, и **только по прямой команде адвоката «публикуй»**.
- **Ссылки на законы РК.** Ссылки и упоминания статей законов Республики Казахстан (Конституция, УПК РК и т. п.) в текстах сайта **не менять и не добавлять без проверки адвоката**.
- **Персональные данные.** Репозиторий **публичный** — персональные данные клиентов (ФИО, детали дел и т. п.) в репозиторий не добавлять.

## Запуск локально
- Зависимости: `npm install`.
- Проверка сборки: `npm run build`.
- Локальный просмотр: `npm run dev` → http://localhost:3000.
